To-Do List
A simple browser-based to-do list app built with vanilla HTML, CSS, and JavaScript. Tasks are saved to localStorage so they persist across page refreshes.
Features
• Add tasks by typing in the input field and clicking Add or pressing Enter
• Mark tasks as complete by clicking on them — completed tasks show a strikethrough
• Delete individual tasks with the × button
• Remaining task count updates in real time
• Tasks persist in localStorage across page refreshes
• Empty state message shown when there are no tasks

Tech Stack
HTML — Semantic markup with a single-page layout
CSS — Custom styling with Inter font, smooth transitions, hover states
JavaScript — Vanilla JS — no frameworks or libraries
localStorage — Browser storage for task persistence

Project Structure
index.html   App markup — input field, task list, remaining badge
style.css   All styling — layout, task items, hover states, completed styles
script.js   All logic — add, delete, complete toggle, localStorage, render

Getting Started
No build tools or dependencies required. Just open index.html in your browser.
git clone https://github.com/vinn-devv/<repo-name>
Then open index.html directly in any browser — no server needed.
